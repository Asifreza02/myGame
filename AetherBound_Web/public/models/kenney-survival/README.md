# Kenney Survival Kit models

These local GLB models come from Kenney's [Survival Kit](https://kenney.nl/assets/survival-kit) (version 2.0). The pack is released under CC0 1.0; the original license is included in `LICENSE.txt`.

This project bundles selected models from the pack: trees, rocks, grass, resource pickups, a barrel, and a metal panel. The models load from this folder at runtime, so gameplay does not depend on an external asset host.
